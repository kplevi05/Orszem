# OpenStreetMap railway data

Railway reference review snapshots generated by `scripts/build-osm-railway-reference.py`
contain data from OpenStreetMap contributors, obtained through the Geofabrik Hungary
extract.

- Source: <https://www.openstreetmap.org/copyright>
- Extract provider: <https://download.geofabrik.de/europe/hungary.html>
- Licence: Open Data Commons Open Database License 1.0 (ODbL)
- Licence text: <https://opendatacommons.org/licenses/odbl/1-0/>

OpenStreetMap data is © OpenStreetMap contributors. The source extract date and SHA-256
are recorded in each generated manifest. OSM-derived railway tables remain attributable
and share-alike under ODbL. The independent KSH settlement table retains its CC BY 4.0
attribution; see `KSH-helysegnevtar.md`.

The first generated output is a review database, not an assertion of official Hungarian
railway jurisdiction and not an importable production release: its manifest remains
`verificationStatus: UNVERIFIED` until a separate reviewed promotion decision.
