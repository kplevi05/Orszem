# Őrszem V2 — common-password blocklist
#
# SOURCE AND LICENCE
# ------------------
# This list is curated specifically for this project. No third-party dataset has been
# copied, so there is no upstream licence or attribution obligation to carry. It is
# deliberately small and maintainable rather than a dump of millions of leaked passwords:
# the goal is to reject the obvious, not to reimplement a breach corpus.
#
# WHY THESE ENTRIES AND NOT THE USUAL ONES
# ----------------------------------------
# The password policy requires at least 15 Unicode code points. That single rule already
# rejects almost every classic weak password — "password", "123456", "qwerty", "admin"
# and the rest are far too short to reach this check.
#
# So a conventional "top 10000 passwords" list would be almost entirely dead weight here.
# What actually threatens a 15-character minimum is the small set of ways people reach
# that length without adding real entropy:
#
#   * repeating a weak word until it is long enough  (passwordpassword)
#   * long keyboard walks                            (qwertyuiopasdfgh)
#   * long digit runs and simple counting            (123456789012345)
#   * a single repeated character                    (aaaaaaaaaaaaaaa)
#   * the well-known long passphrases                (correcthorsebatterystaple)
#   * project, product and domain names              (orszembejelento)
#
# Entries are compared after folding to NFC, lower-case (Locale.ROOT) and trimming
# surrounding whitespace, so only one casing of each needs to be listed here.
#
# Maintenance: add an entry when a real weak-password pattern is observed. Do not bulk
# import — a large list here buys very little on top of the length rule and makes review
# impossible.
